# OctoFit Tracker (Frontend)

React + Vite UI for OctoFit Tracker.

## Development

npm install --prefix octofit-tracker/frontend
npm run dev --prefix octofit-tracker/frontend

## Environment

If running in Codespaces, set VITE_CODESPACE_NAME in octofit-tracker/frontend/.env.local (see .env.example).
The app expects the API on port 8000 (http://localhost:8000 or https://<codespace>-8000.app.github.dev).
